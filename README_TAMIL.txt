New Science World – Students Zone
=================================

இது ஆரம்ப Study App திட்டம்.

Laptop-இல் பார்க்க:
1. ZIP கோப்பை Extract செய்யவும்.
2. index.html மீது double-click செய்யவும்.
3. Chrome அல்லது Edge-இல் App திறக்கும்.

கோப்புகள்:
- index.html : App அமைப்பு
- style.css  : வடிவமைப்பு
- app.js     : Notes, quiz, buttons செயல்பாடு
- manifest.json மற்றும் sw.js : PWA அடிப்படை கோப்புகள்

மாணவர்களுடன் பகிர:
1. App-ஐ இணையத்தில் வெளியிட வேண்டும். GitHub Pages போன்ற static hosting சேவையைப் பயன்படுத்தலாம்.
2. இந்த folder-இல் உள்ள கோப்புகளை hosting சேவையில் upload செய்யவும்.
3. கிடைக்கும் website link-ஐ மாணவர்களுக்கு அனுப்பவும்.

கவனம்:
- இப்போது உள்ள Notes மற்றும் Quiz எடுத்துக்காட்டு உள்ளடக்கம் மட்டுமே.
- PDF/Video இணைப்புகளை நீங்களே சேர்க்க வேண்டும்.
- இணையத்தில் வெளியிடும் முன் எல்லா பாட உள்ளடக்கங்களையும் சரிபார்க்கவும்.
